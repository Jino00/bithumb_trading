# 작업 기억 시스템 (Work Memory)

AI의 기억력 한계를 보완하기 위한 파일 기반 기억 시스템.
큰 작업을 시작할 때 반드시 아래 3개 문서를 생성한다.

## 문서 구조

### 1. plan-[작업명].md (계획서 = 설계도)
- 우리가 뭘 만들 건지 처음부터 끝까지 기록
- AI가 계획을 세우면 → 검토 → 승인 → 이 파일에 저장

### 2. context-[작업명].md (맥락노트 = 시방서)
- 왜 이렇게 결정했는지
- 관련 자료 위치
- 기술적 제약사항

### 3. checklist-[작업명].md (체크리스트 = 공정표)
- [ ] 할 일 목록
- [x] 완료된 항목
- 작업 중간중간 업데이트 필수

## 사용 규칙
1. 큰 작업 시작 → 3개 문서 먼저 생성
2. 계획이 승인되면 → 바로 코딩하지 말고 문서 먼저 저장
3. 한 번에 1~2개 작업만 진행
4. 작업 완료 시 → 체크리스트 업데이트
5. 새 대화 시작 시 → 이 문서들을 먼저 읽고 이어서 작업

## 파일 목록
- `modified-files.log`: 수정된 파일 자동 추적 로그 (hooks에서 자동 기록)
- `decisions.md`: 중요 결정 사항 기록
