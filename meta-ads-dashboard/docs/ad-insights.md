## 3. 제품별 성과 요약

### TPU 지문방지필름 (주력 상품)
- **최고 ROAS**: 1.97x (A+SC 흔들기_S26) / 1.78x (제리 영상_S26)
- **성공 크리에이티브**: 흔들기 비교, 빛반사 비교, 제리 캐릭터 영상
- **핵심 카피**: 지문 스트레스 → 해결 / 햇빛 반사 → 선명 / EZ툴 간편 부착
- **최적 예산**: 일 ₩30,000~70,000
- **주의**: 인지도/트래픽 목표로 돌리면 ROAS 0.19x까지 하락

### 셀카봉
- **ROAS**: 2.19x (A+_샐카봉) / 1.42x (셀카봉 V2) / 1.19x (셀카봉 논타겟 영상)
- **성공 요인**: A+ Shopping Campaign + 충동구매 유도 가격대
- **최적 예산**: 일 ₩20,000

### 일미리 케이스
- **ROAS**: 2.31x (최고 성과 — 구매 612건)
- **성공 요인**: 논타겟 + ₩30,000 예산 + 누적 학습 데이터 풍부
- **주의**: 트래픽 캠페인으로 돌리면 ROAS 0.62x / 쿠팡 랜딩 시 0.00x

### 버디필름 (골프)
- **ROAS**: 1.33x (260228_[어+] 버디필름) / 1.28x ([테스트] 버디필름)
- **성공 요인**: 비거리 향상 + 슬라이스 방지 = 구체적 효과 소구
- **주의**: 관심사(골프) 타겟이 의외로 작동 — 골프는 니치 시장이라 관심사 허용 가능

### 맥세이프 가죽지갑
- **ROAS**: 0.75~0.96x (전체 적자)
- **실패 원인**: CPC ₩855~889로 높음 + AOV 대비 마진 부족
- **판단**: 이 제품은 Meta 광고 효율이 낮음, 다른 채널 검토 필요

### 문캅스 (도어락 필름)
- **ROAS**: 0.87~1.24x (손익분기 수준)
- **카피**: "도어락 비밀번호 유출" 보안 소구 — 독특하지만 전환 약함
- **판단**: 니치 시장으로 모수 부족, 스케일 어려움

### 강화유리필름
- **ROAS**: 0.34~1.09x (대부분 적자)
- **실패 원인**: CCFM 시리즈 픽셀 혼용 + 소재한정 + 높은 CPC
- **판단**: 크리에이티브와 픽셀 정비 후 재도전 필요

## 5. 앞으로의 광고 세팅 원칙 요약

1. **PURCHASE 전환 캠페인만** — 트래픽/인지도는 이 가격대에 효과 없음
2. **무조건 브로드 타겟** — Meta AI에게 최대 자유도 부여
3. **Cafe24 픽셀 통일** — 학습 데이터 집중
4. **검증된 크리에이티브 복제** — 흔들기, 제리, A+SC, 빛반사 포맷
5. **일 예산 ₩20K~70K** — 학습 충분 + 비효율 방지
6. **새 소재는 차별화** — 같은 카피 복사 금지, 각도/메시지 변경
7. **자사몰 랜딩만** — 쿠팡/스마트스토어 랜딩 금지
