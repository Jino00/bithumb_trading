# CLAUDE.md — meta-ads-dashboard

## 프로젝트 개요
Meta 광고 성과 대시보드 + Cafe24 자사몰 연동.
수익성 분석, 캠페인 자동 진단, AI 광고 카피 생성.

## 기술 스택
- Backend: Node.js ESM, Express, better-sqlite3
- Frontend: TypeScript, React, Vite, Tailwind CSS
- AI: Claude API, Gemini API

## 실행 방법
```bash
cd meta-ads-dashboard && bash start.sh
# Backend: http://localhost:3001
# Frontend: http://localhost:5173
```

## 상황-행동 규칙 (반드시 준수)

### 🔴 절대 원칙: 같은 계산을 2곳에 쓰지 마라
- 비즈니스 계산(수익성, ROAS 등)이 필요하면 → `services/biz-metrics.js` 확인 후 사용한다
- 숫자 반올림이 필요하면 → `roundN()` 사용한다. Math.round / toFixed 직접 쓰지 않는다
- 프론트엔드에서 재무 지표를 표시하면 → 백엔드 API 응답을 그대로 쓴다. 프론트에서 재계산 금지
- 새 비즈니스 공식이 필요하면 → `biz-metrics.js`에 추가한다. 사용 파일에 직접 작성 금지
- 같은 로직이 2개 파일에 있으면 → 공유 모듈로 추출한다 (backend: services/, frontend: lib/)

### 데이터 흐름 규칙
- 재무 데이터 계산 흐름: Raw Data → biz-metrics.js → route → API 응답 → 프론트 표시
- 기간(period) 필터가 필요한 API는 → Meta API에서 직접 조회한다. DB 누적 데이터 사용 금지
- DB 스키마 변경 시 → 프론트 TypeScript 인터페이스(api.ts)도 함께 업데이트

### 코드 구조 규칙
- 함수 30줄 초과 시 → 분리한다
- 새 파일 생성 시 → 맨 위에 한 줄 주석으로 역할 기술
- 외부 API 호출 시 → try/catch 필수 + 에러 시 적절한 HTTP 상태코드 반환
- 매직넘버 → 이름 있는 상수로 추출

### 공유 모듈 위치 규칙
| 종류 | Backend 위치 | Frontend 위치 |
|------|-------------|--------------|
| 비즈니스 계산 | services/biz-metrics.js | 사용 금지 (API 호출) |
| UI 포매팅 | 해당 없음 | lib/utils.ts |
| API 타입/호출 | 해당 없음 | lib/api.ts |
| DB 접근 | db/database.js | 해당 없음 |

## 🎯 광고 세팅 규칙 (실제 데이터 기반 — 반드시 준수)

> 64개 캠페인, 170개 광고의 누적 성과 분석 결과.
> 상세 데이터는 `docs/ad-insights.md` 참조.

### 캠페인 세팅
- 새 캠페인을 만들면 → 목표는 반드시 **OUTCOME_SALES + PURCHASE 최적화**로 설정한다
- 트래픽/인지도 목표 캠페인은 → 만들지 않는다 (₩180만 소진, 직접 구매 0건 실증)
- 입찰 전략은 → **LOWEST_COST(자동)** 사용한다. MIN_ROAS 입찰은 모수 부족 시 노출 자체가 줄어 학습 불가
- 일 예산은 → **₩20,000~70,000** 범위로 설정한다. 너무 낮으면 학습 부족, 너무 높으면 비효율

### 타겟팅 세팅
- 타겟팅은 → **논타겟(브로드) 18-65세, 성별 무관, 한국** 으로 설정한다
- 관심사 타겟은 → 사용하지 않는다 (관심사 타겟 캠페인은 대부분 ROAS 0.0x, 논타겟이 압도적 우위)
- 성별 제한은 → 하지 않는다 (여성 한정 캠페인 ₩49K 소진 구매 0건)
- 연령 좁히기는 → 하지 않는다 (20대 한정 등 좁은 연령대는 CPC 2~4배 상승)

### 크리에이티브 세팅
- Advantage+ 자동 소재 최적화를 → 항상 허용한다 (소재한정 캠페인은 성과 저하)
- 같은 카피로 광고 10개 복사는 → 하지 않는다 (차별화 없는 수량 증가는 무의미)
- CTA 버튼은 → **SHOP_NOW** 또는 **LEARN_MORE** 사용한다
- 검증된 크리에이티브 패턴:
  - **흔들기 영상**: 필름 효과를 좌우 비교로 직관 시연 (ROAS 1.97x)
  - **캐릭터 영상(제리)**: 주목도↑ + SHOP_NOW (ROAS 1.78x)
  - **A+SC(Advantage+ Shopping)**: Meta 자동 최적화 소재 (ROAS 2.19x)
  - **빛반사 비교 영상**: 문제→해결 구조 (ROAS 1.70x)
- 카피 공식: **공감형 문제 제기 → 해결책 → 사회적 증거(리뷰 수)**
  - 예: "지문 스트레스 → 오하이 매트필름 → 21,000개 리뷰"
